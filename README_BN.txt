KTM Cartoon LIVE Painter V10 — Android WebView Project

এই ZIP-এ Android Studio/AndroidIDE-তে খোলার মতো source project আছে।
এটি নিজে থেকে তৈরি APK নয়; APK বানাতে Android SDK/Gradle build প্রয়োজন।

Android-এ APK build:
1) ZIP extract করুন।
2) AndroidIDE বা Android Studio-তে KTM_Cartoon_Live_Painter_V10_Android ফোল্ডার open করুন।
3) Gradle sync শেষ হতে দিন; SDK 35 ও JDK 17 প্রয়োজন হতে পারে।
4) Build > Build APK(s) নির্বাচন করুন।
5) app/build/outputs/apk/debug/app-debug.apk ফাইলটি পাবেন।

V10 এখন অফলাইন demo। Follow/Gift বোতাম দিয়ে পরীক্ষা হয়।
